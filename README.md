# Web Data Scrapping for E-Commerce Analytics
Extracted and analyzed product pricing and reviews from `kickavenue.com` to provide actionable insights.

## Overview

This project focuses on extracting and analyzing product pricing sneakers men from `kickavenue.com` to provide actionable insights for eCommerce analytics. By leveraging web scraping techniques, the collected data is included product names, price, images and product link. The data that has been obtained then processed to CSV format and load the data to database PostgreSQL.

## Features
- Product Pricing Analysis       : Ectract real-time product prices to track market trends.
- Data Cleaning & Transformation : Process raw data for meaningful analysis.
- Load Data                      : Save to CSV format then load the data to database PostgreSQL

## Technologies Used
- Python            : Core progamming language for scraping and data analysis.
- Selenium          : Navigate websites and interact with web pages.
- BeautifulScoup    : Web scrappping libraries.
- Pandas            : Data cleaning and transformation.
- PostgreSQL        : Database load.

## Data Source
Data is extracted from `kickavenue.com`, a popular online marketplace for sneakers and streetwear.
